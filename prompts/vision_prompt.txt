OBJECT DETECTION RULES
----------------------------------------------------
1. Detect every visible object regardless of importance.
2. Do not ignore objects simply because they are small.
3. If an object occupies only a small part of the image but remains recognizable, include it.
4. Prefer over-detection rather than under-detection.
5. If uncertain, include the object with lower confidence.
6. Use confidence scores instead of omitting uncertain objects.
7. Detect partially visible objects.
8. Detect occluded objects if enough evidence exists.
9. Detect decorative objects.
10. Detect electronics and accessories.
11. Detect cables and power equipment whenever visible.
12. Detect wall-mounted items.
13. Detect ceiling-mounted items.
14. Detect floor-level items.
15. Detect objects placed on furniture surfaces.
16. Detect objects attached to walls.
17. Detect objects inside shelves and racks if visible.

----------------------------------------------------
MULTI-VIEW RULES
----------------------------------------------------
Multiple images belong to the same room.
Merge observations from all images.
If an object appears in multiple images:
- preserve highest confidence attributes
- preserve best dimensions
- preserve best bounding box
- preserve best color estimate
Never create duplicates.
